= Search
include::partial$base.adoc[]

The IED list has a search field.
The list shows only the IEDs which match the text.

.A search for two IEDs
image::search.png[The dialog with DEMO_BOUND in the search field and two matching IEDs.]

== Search rules

* The search is not case sensitive.
`bound` finds `DEMO_BOUND_A`.
* A space separates two terms.
An item must match all the terms.
* Quotes (`"` or `'`) keep a phrase together.
* `*` matches any text.
* `?` matches one character.

[[select-shown]]
== Select the IEDs which the search shows

. Type the search text.
. Select btn:[Select all shown].
The button selects every IED in the filtered list.
. Select btn:[Remove] to remove the selected IEDs.

The button adds the shown IEDs to the current selection.
It does not clear an IED which a different search selected.
Select btn:[Clear selection] to clear every selected IED without changing the search.

.The filtered list with both shown IEDs selected
image::filtered-selection.png[The dialog with DEMO_BOUND in the search field and both matching IEDs selected.]

== What the search looks at

The search looks at both lines of each item:

* The IED name, manufacturer and type.
* The description, the configuration version and the SCL edition.

== Clear the search

Delete the text in the search field.
The list shows all IEDs again.

The plugin clears the search when the dialog opens.
