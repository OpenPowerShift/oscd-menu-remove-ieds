== What is this?

This plugin removes one or more IEDs from an SCL file.
It is a menu plugin for OpenSCD.
It uses the `oscd-edit-v2` event and the `doc` and `docVersion` plugin properties.

The plugin removes the data which refers to the selected IEDs:

* The `IED` and `AccessPoint` elements.
* `ConnectedAP`, `GSE` and `SMV` addresses.
* `Association`, `ClientLN` and `KDC` elements.
* `IEDName` text content.
* Subscriptions and supervisions in other IEDs.

Associated `LNode` elements are preserved with `iedName="None"` by default.
The dialog can delete them instead.
The dialog can also delete a `SubNetwork` or a `Communication` section which the removal empties.
Both section deletions are off by default and show a schema warning.

All changes from one removal are one undoable action.

See the {uri-docs}[documentation] or {uri-demo}[try it online].

== Add the plugin

Add this entry to the `menu` plugins of an OpenSCD distribution:

[source,json,subs=+attributes]
----
{
  "name": "{plugin-title}",
  "icon": "delete",
  "requireDoc": true,
  "src": "{uri-bundle}"
}
----

The host must supply `doc` and a reactive `docVersion`.
A host which supplies only the legacy `editCount` does not work.

To use a release, install the {uri-npm}[npm package] and set `src` to its bundle.

== Development

The plugin uses Node.js 22 and `@omicronenergy/oscd-tooling`.

 $ npm install
 $ npm run start

Open `http://localhost:8000/demo/` in a browser.

[cols="1,2"]
|===
|Command |Purpose

|`npm run lint`
|Run the linter.

|`npm test`
|Run the unit and component tests with coverage.

|`npm run build`
|Build `dist/`.

|`npm run bundle`
|Build the plugin bundle and the demo.

|`npm run test:visual`
|Run the screenshot tests.
|===

The screenshot baselines are owned by CI.
Do not create or update them on a development machine.

See {uri-docs}[the documentation] for the architecture, the test strategy, the screenshot workflow and the release setup.
